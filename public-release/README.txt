FEFW CoreMods 0.2.8 公开版（2026-11-20）

适配 fefw-recomp 0.2.8 Windows 版（Goldoire v0.2.0 之后的社区延续版）与游戏更新 131072。请选择与转译器版本相同的安装包，不能把 0.2.0 和 0.2.8 的运行库混用。

先阅读「使用说明.txt」，再关闭游戏和启动器，运行 install.cmd。安装器会核对原版文件、保留备份，并用你自己的游戏文件在本机重新构建游戏程序。压缩包不含游戏本体、密钥、存档、着色器缓存或生成的 fefw.exe。

本版把 CoreMods 全部功能移植到 0.2.8 运行库：F1 → Core mods 的倍率、人物成长、声望、物品添加与送礼值、出击人数（6～25）、手动存档、超难选项、因果祭坛难度与模式切换、新入队角色等级、步兵系武器／战技解锁、「解除特殊职业人数限制」与「解除转职章节限制」（均默认关闭）与 0.2.8 的帧率修复、画面细节、图形预设共存。对应源码在 source.zip；来源和许可见「来源与授权.txt」。

安装遇到文件版本或路径检查提示时，请看「故障处理.txt」。不要跳过文件核验，也不要把安装包覆盖到另一版本的游戏目录。
