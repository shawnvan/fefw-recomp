FEFW CoreMods 0.2.8 使用说明

安装与更新

1. 确认你使用的是官方 fefw-recomp 0.2.8 Windows 版，并已用自己的游戏更新 131072 完成 Set up。退出游戏和启动器，先备份要保留的存档。
2. 解压整个压缩包，把 CoreMods-public 文件夹放在 fefw-launcher.exe 旁边，运行其中的 install.cmd。安装器会核对版本、保存原文件，并在本机重建 fefw.exe。
3. 已装过同版本 CoreMods 的用户，同样先退出游戏，替换整个 CoreMods-public 文件夹后运行新的 install.cmd。安装器会留下更新前的程序备份，并重新生成物品中文目录。不要沿用另一个转译器版本的包。
4. 进游戏按 F1 打开设置。想卸载时先退出游戏，再运行 CoreMods-public\uninstall.cmd；存档不会随卸载删除。

常用设置

· Core mods 的倍率、移动消耗和转职补正，全新安装默认为游戏原版。倍率 1 倍是原版，0 倍表示没有收益。页面总开关关闭后会暂时按原版计算，原先调好的滑块数值保留。复位按钮需要在提示后再点一次。
· 人物成长页可选择随机、固定或沿用游戏原来的成长方式。全局补正对本机所有存档共用，HP 按双倍百分点增加；角色的独立补正只属于当前存档，代替该属性的全局值。设好独立补正后请在游戏内保存。成长估算以当前角色、当前职业为准；属性碰到上限时仍不能继续增加。
· 普通战斗的自选出击名额默认为 6 人。可以在 6～25 之间调整，用上下箭头改数字并点旁边「确定」，重启游戏后生效。固定人物和 GUEST 另外计入，但实际出场总数最多 25 人；剧情或特殊关卡的原有规则与可用位置可能限制出场。
· 当前存档声望既可用滑块，也可输入增加或减少的数量。输入后连续点两次「确定」才会修改；结果受当前章节和总上限限制，总上限为 10800。
· 物品页可跨分类勾选多种物品，填「每种物品的数量」后直接加入背包。敌人专用条目与魔法技能显示在不可添加的独立分类中。页面里的中文目录由安装器从你自己的游戏文件生成；旧的购买或拾取触发逻辑仍留在代码中作备选。
· 「解锁步兵系职业武器／战技限制」只作用于步兵系，改动后需要重启。新入队角色等级、因果祭坛难度与轻松／经典模式切换等标有重启提示的功能，同样请在重启后验证。
· 「解除转职章节限制」位于 F1 → Core mods，与「解除特殊职业人数限制」同一行，默认关闭。开启后第一部可预览并报考最高级职业；考试通过后按正常流程在「更换兵种」转职。等级、熟练度、准考证和成功率继续按原规则，隐藏职业自身的条件不因此解除。修改后请重新打开资格考试界面。
· 手动存档、无限消耗及其他开关可按需开启。修改当前存档内容后请使用游戏内保存；首次测试新设置时建议保留一个改动前的存档栏位。

如果安装器提示版本不匹配，请先核对转译器版本与原版文件，不要强行替换运行库。需要恢复原文件时，运行 uninstall.cmd。更多信息见「故障处理.txt」。
